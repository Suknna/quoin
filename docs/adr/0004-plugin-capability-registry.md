# 插件驱动的接入、观测与 Agent 工具

## Context

BusinessSystem 曾同时承担接入选择、资源范围、查询授权和巡检计划的权威，导致用户在接入监控后仍须发布业务声明才能使用。2026-09-13 批准将接入、自动观测和可选业务视图分离，并要求插件可以提供模型工具；浏览器也作为可选插件，不再成为默认部署的依赖。

此决定替代 ADR 0002 中“接入不采集／仅任务触发采集”以及 ADR 0003 中“业务声明为所有观测、查询和巡检的必要来源”的当前约束。两份旧 ADR 保留其历史意义。本决定不改变历史执行的来源和授权，不是实施或验收已完成的声明。

## Decision

### 插件与执行边界

使用可信、构建期显式注册的插件。部署 YAML 选择启用插件；扩展需要实现能力接口、注册并随组件版本发布，不提供在线安装任意代码、动态 Go shared object 或第二套插件 RPC。

插件描述声明稳定身份、版本、配置形状和实际支持的能力。静态配置验证为必需能力；连接探测、对象观测、模型工具、工具执行、巡检模板和采证按需组合。控制面描述与运行时执行绑定分离；声明不能伪装不存在的实现。

Quoin 拥有配置、授权、调度和权威结果。出站插件在既有受控执行宿主中运行，秘密仅在授权的执行边界解析。Agent worker 不获得端点凭据、浏览器 profile 或外部网络权限。Alertmanager 接收继续遵循 Stele 的转交与 Quoin 事务确认边界。

### 工具目录

插件提供封闭参数与结果 Schema、说明、版本、执行位置、授权需求和 Evidence 行为。模型只能调用本次执行冻结目录内的工具。规范目录和摘要由控制面与 worker 共享，实际 Model Call 保存所用目录摘要与来源。

每次执行再次验证接入授权、插件启用和取消状态；冻结目录不能使已经停用的能力继续接受新执行。工具名冲突、非法 Schema、声明与执行不一致必须拒绝。外部返回数据不具备修改工具目录、系统指令或访问范围的权限。

### 接入、观测与业务视图

管理员验证并启用接入后，支持观测的插件自动执行有界观测。接入凭据及明确的收窄约束定义访问边界；业务视图不能增加权限。

活动资源身份由来源接入、对象类型和规范来源身份确定，不依赖业务分组。跨来源同名对象不自动合并。只有同一冻结范围内完整成功观测才能表达未再观测到；失败、局部结果和截断不得清空资源，也不推断物理删除。

业务视图是可选、版本化的范围与说明；表单和 YAML 编辑同一个对象。不建立业务视图也必须能够接收告警、观测资源、使用已授权的 Agent tools 和执行基础巡检。缺少明确的数据源关联时保留歧义，不回退到第一个接入。

### 巡检与报告

巡检计划独立选择接入、对象集合或业务视图。插件贡献版本化模板和采证能力，统一调度器在创建 Run 时确定性展开并冻结目标、接入修订、授权、模板和查询窗口。执行中发现的新对象不改变已经冻结的 Run。

确定性程序采证，模型基于持久化 Evidence 和缺口产生不可变报告。插件不直接写权威报告。采证成功不等于业务健康；缺失指标或未声明业务标准不能解释为检查通过。模型不可用不使已采集的事实丢失，重新分析与重新采集保持独立。

自动观测默认运行；持续巡检和模型报告需要明确启用，不因保存凭据而无提示产生持续模型费用。

### 浏览器可选

浏览器插件默认不启用。默认工具目录、巡检模板、管理入口、路由、部署和就绪检查不得依赖 Lintel。显式启用后才连接现有浏览器执行器，保留人工登录、身份独占、容量控制、持久卷和秘密隔离。

未启用不等于故障。现有浏览器历史可以只读保留；禁止因为移除默认部署而删除身份卷或改写历史。

### 切换与历史

移除旧业务声明调度、强制业务范围写入口及硬编码插件执行接线，不双写、不保留旧活动执行开关。历史只读解释和一次性迁移不属于兼容执行路径。

迁移保留原权限和范围。无法机械等价转换时明确阻断或标记待处理，不自动扩大到全接入；不能证明身份等价时保留旧历史而不伪装为当前资源。迁移必须通过维护、备份和活动任务检查，不直接操作现有运行数据卷。

## Verification

接口定义及开发规范分别见 `docs/specs/quoin-v1/plugins.md` 和 `docs/plugin-development.md`，以实际类型和契约测试为准。

交付必须使用 `deploy/` 下的 Dockerfile 构建镜像和 YAML 部署，结合 `.local-lab/` 的真实业务及监控服务，通过外部测试浏览器完成登录、接入、观测、Agent tool、巡检报告、业务视图与告警链路点击验证。默认不启用浏览器插件的主线与显式启用插件的场景分别验收。MSW、旧截图、历史 STATUS 或直接 API 调用不能替代本次真实浏览器验收。

构建和部署身份、实际操作及结果记录在 `docs/plugin-real-deployment-acceptance.md`。缺少模型或依赖时如实记录阻塞，不将未执行项目标记通过。
