## 真实故障链

1. 管理员关于页显示 Plinth `registered`、真实 `v0.1.0-dev` 和连接事实，未注册 Lintel 的版本/最近事实显示未知。
2. 只停止隔离环境中的 Plinth 容器。统一当前告警实时出现 `platform:1`、平台内部来源及 `runtime_control_stream_disconnected`。
3. 实际点击列表行打开详情。详情显示发生时间、尚未恢复、组件和原因；无上游 Observation 时间线或 AI 分析入口，并明确说明不会启动业务采集。
4. 保持详情打开，启动同一 Plinth。无需刷新，原详情变为 `Resolved` 并显示恢复时间，当前列表移除该行。
5. 该轮视觉检查发现顶部计数未随 SSE 更新；随后补充测试并修复为重新读取真实当前/历史快照，平台详情说明也不再声称存在上游观察/分析。上述 firing/resolved 原始截图记录的是修复前的计数问题，不作为计数修复通过证据。
